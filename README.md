# Project Minos

A top-down, procedurally generated dungeon crawler. Each floor is a maze generated as you explore it.

- Play: open `project-minos.html` in a browser (WASD or arrow keys to move, Space to swing, R to return to the safe room after dying; T toggles the skeleton test arena, where 1-5 set skeleton difficulty).
- Test: `node tools/test-room.js`
